# concept — a subject that does not produce code

## Pick this when
the subject does not produce code: marketing, growth, strategy, AI concepts, comp sci theory, design, history.

## Artifact floor
written output you wrote, even a paragraph. More load-bearing than on the code track, because there is no compiler forcing production.

## Session shape
A: 15 min one concept via a sourced page, case first, 45 min apply it to a different case or counterfactual, 30 min write this session's artifact increment, 30 min consolidate. B: 10 min mandatory retrieval, 80 min produce, 30 min review. C: flex, explain the concept and take pushback.

## Mastery gate
declarative: teach the concept from memory with the sources closed. Judgment concepts defend a decision against one counter-case.

## Verify exercise
spot the flawed claim: a short argument using the week's concept, sometimes sound and sometimes subtly wrong.

## Sequencing
project-first. Anchored to a real applied artifact you would use.
